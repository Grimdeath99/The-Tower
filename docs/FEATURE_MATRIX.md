# Feature matrix

Source **MP §N** means section N of [the supplied master prompt](Vertical_District_Master_Coding_Prompt.md); **BO §N** means FULL BUSINESS OPERATIONS AND FACILITY COVERAGE; **AT §N** means the latest ADVANCED TRANSPORT AND LOCATION-SPECIFIC INFRASTRUCTURE request. Master-prompt phases are numbered 0–8. Current work prioritizes coordinated banks and real transfers; the [retail slice](RETAIL_OPERATIONS.md) and [catalogue/ownership foundation](BUSINESS_OPERATIONS.md) remain established workloads. E01–E33 are earlier evidence; E34 onward records transport. The missing approved GDD, selected edition and exact 87-entry list remain unavailable.

Statuses apply only to each row's stated acceptance scope. **Verified** requires executed evidence; **Implemented** means connected code exists but its stated acceptance is pending. Broad partially complete requirements remain **In Progress**. Evidence IDs refer to [PROJECT_STATUS.md](PROJECT_STATUS.md).
